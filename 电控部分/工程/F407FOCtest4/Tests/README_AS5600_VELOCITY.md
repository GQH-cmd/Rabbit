## 覆盖的错误

- 冷启动绝对角度不应制造速度；微秒时间戳为0不是未初始化标志。
- 静止输入在相邻1–2个计数之间摆动，固定/非均匀采样不应被放大到65 RPM以上。
- 没有新的角度读取时，多次控制函数调用不得制造新的零速度测量或衰减原速度。
- 角度读取完成时刻与控制调用时刻分开；调用延迟不得替代采样时间。
- 正反向70/100/300/1000 RPM输入均能识别真实运动，不能通过强制填零掩盖超限。
- 两路独立历史、角度跨圈、32位微秒计数回绕。
- 真正停止后的衰减、长采样间隔重新建立基准；长间隔保留上次值，不把未知速度强行填零。
- I2C读取失败仍停两路电机、禁用失败编码器；后续测速不得重新产生伪速度。

预期转速由每圈4096个原始计数和已知模拟运动生成，不使用生产滤波函数计算期望值。`--source-root` 可运行备份版本的真实驱动，以复核 RED/GREEN。

## 实机边界

1ms最小差分窗口及5ms低通时间常数仅为本次候选实现。它们改变速度反馈动态，即使PID参数未改，仍须在后续受控台架上重新验证闭环稳定性和接触停止行为。

主机测试只说明这些输入下算法行为正确，不证明现场磁铁、编码器I2C读数、采样周期、供电或机械动作已经验证。本轮只测试和编译STM32候选固件，不自动刷写，也不把代码修改当成实际喂奶故障已经修复。
